# @kinetone/ui

kinetone のアプリで共通に使う CSS を配るパッケージです。ファイルは `global.css` の 1 本だけで、
JavaScript は入っていません。

これまで `src/ui/global.css` を各リポジトリにコピーしていたため、直しても配る手段がなく、
同じ残骸が複数のリポジトリに残っていました。ここを配布元にします。

**対象は明るい地の系統（A）だけです。**
測定系（chair-stand / one-leg-stand / stepping / mahjong）は、レクと取り違えないよう
意図的に暗い配色にしています。地の明暗が逆なので、このパッケージは使いません。

## 使い方

`package.json` に足します。バージョンはタグで固定します。

```json
{
  "dependencies": {
    "@kinetone/ui": "github:researchcoordinate/kinetone-ui#v0.1.0"
  }
}
```

アプリの入口（`src/App.tsx` など）で読み込みます。ゲーム固有の CSS より**先に**書いてください。
後から読んだ側が勝つので、順番を逆にすると上書きのつもりが効かなくなります。

```ts
import '@kinetone/ui/global.css'
import './ui/game.css'
```

これまで各アプリにあった `src/ui/global.css` は消して構いません。

## 入っているもの

### CSS 変数

| 変数 | 用途 |
| --- | --- |
| `--bg` / `--bg-2` | 地。`body` の線形グラデーションの薄い側と濃い側 |
| `--panel` | カードなど狭い面の地 |
| `--line` | 罫線 |
| `--text` | 本文 |
| `--text-dim` | 補助的な文字 |
| `--btn-bg` / `--btn-ink` | 主要アクションの面と文字 |
| `--accent-line` | 明るい地の上でアクセントを文字や線にするとき |
| `--accent` | 映像や景色の上（暗い面）で使う明るいアクセント |
| `--bad` | 異常や警告の枠線（`.alert` が使用） |
| `--fs-hero` / `--fs-xl` / `--fs-lg` / `--fs-md` / `--fs-sm` | 文字の大きさ。`clamp()` で画面幅に追従 |
| `--radius` | 角の丸み |

`--content-width` はここでは定義していません。`.screen` が `var(--content-width, 900px)` で
読むだけなので、画面ごとに変えたいときにアプリ側で指定してください。

### 素の要素

`*` の `box-sizing`、`html` / `body` / `#root` の高さと余白、`body` の地・文字色・書体。

### クラス

| クラス | 用途 |
| --- | --- |
| `.screen` | 画面全体。左右の余白で読みやすい幅を作る（`max-width` を使わない理由は CSS 内のコメント参照） |
| `.brand` | ブランド表記 |
| `.title` | 見出し |
| `.subtitle` | 副見出し |
| `.note` | 利用者に読ませる文章 |
| `.card` | カード |
| `.btn` | ボタン。`.btn--huge` / `:focus-visible` / `:disabled` を含む |
| `.alert` | 異常の通知 |

### 冒頭のコメント

`global.css` の先頭 18 行は、配色をこう決めた理由の記録です。加齢による見え方
（瞳孔が縮む、眼内で光が散る、コントラスト感度が落ちる）に基づいています。
**色を足すときは必ず読んでください。** 消さないでください。

## 入っていないもの

共通に置けなかったものです。同名で意味の違うものを共通に置くと、片方を直したときに
もう片方が壊れます。

### `.stage`

`transform: scaleX(-1)`（左右反転）を掛けるかどうかがリポジトリで割れています。
鏡像にするかは、そのアプリが利用者に何を見せているか次第なので、共通の答えがありません。
各アプリの `src/ui/game.css` に置いてください。

### `.meter`

kinetone-tree では「動き量メーター」、kinetone-kikyu では「気球の高度ゲージ」で、
名前が同じだけの別物です。共通に置くと事故ります。各アプリの `src/ui/game.css` に置いてください。

### ゲーム固有のクラス

`.bloom` / `.sound-off` / `.hold` / `.hold__fill` など。そのゲームにしか出てこないものは
共通ではありません。各アプリの `src/ui/game.css` に置いてください。

**ゲーム固有のものを書く場所は、各アプリの `src/ui/game.css` です。**
このパッケージに足すのは、明るい地の系統のすべてのアプリで同じ見た目・同じ意味になるものだけです。

## 削除した CSS 変数

**以前は `global.css` にありましたが、どのアプリからも参照されていなかったので消しました。**
「無いのはうっかりではなく、意図」という記録としてここに残します。足し直す前に下を読んでください。

| 変数 | 元の値 | 削除した理由 |
| --- | --- | --- |
| `--panel-solid` | `#fffdf9` | どのアプリも参照していませんでした。値が `--panel` と同一で、名前だけが別にありました |
| `--good` | `#0e7a52` | 共通の CSS からは参照されていませんでした（下記の但し書き参照） |
| `--warn` | `#a8410a` | 同上 |
| `--accent-ink` | `#2a1a00` | 同上。`--accent` の上に載せる文字色ですが、載せているアプリがありませんでした |

`--bad` は `.alert` が使っているので残しています。

**但し書き:** `--good` / `--warn` / `--accent-ink` は、kinetone-atodashi-janken の
`src/ui/game.css` だけが参照しています（○×の色分けなど、あのゲーム固有の表現です）。
共通ではないので、このパッケージには戻さず、**kinetone-atodashi-janken 側の `game.css` の
`:root` に自前で定義してください。**

足し直したくなったときは、まず「これは全アプリで同じ意味になるか」を確かめてください。
1 つのアプリだけが使うなら、そのアプリの `game.css` が置き場所です。

**裏付け:** どの変数がどのリポジトリで参照されていなかったかは、
[`docs/global-css-diff.md`](docs/global-css-diff.md) の「4.1 参照されていない CSS 変数」に
リポジトリごとの一覧があります（`--panel-solid` は 11 本中 8 本で未参照、など）。
このパッケージを切り出す前に 19 リポジトリを横断で調べた記録で、
`.stage` と `.meter` を共通に入れなかった理由の実データもそこにあります。

## 色を足すときの決まり

地に対して、本文は 4.5:1、大きな文字でも 3:1 を必ず超えること。
高齢者はコントラスト感度が落ちるので、規格ぎりぎりではなく余裕を持たせてください。
既存の変数のコメントに実測のコントラスト比を書いてあります。足すときも同じように書いてください。
